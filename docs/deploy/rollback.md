# Откат

`bash deploy/rollback.sh PREVIOUS_COMMIT_SHA` от deploy проверяет SHA/realpath/RELEASE, атомарно меняет current и перезапускает только сервис проекта. После этого проверяются ready, dashboard, file→UI, auth и SSE. Предыдущий каталог не удаляется. Обратимых изменений схемы не требуется: текущая миграция только добавляет таблицы/индексы.

Восстановление БД — отдельная операция по backup-restore.md, только после сравнения сохранённых данных и остановки writer. Не заменять новые рабочие данные старым dump автоматически. На закрытом VDS-стенде выполнен переход 64c9105 → a5b35d4 → 64c9105. Копии скриптов использовали выделенные каталоги, wmrestore, loopback-порт и systemctl --user. На каждом шаге проверены рабочий каталог действующего процесса, готовность, 600 записей и ревизия 5. Откат системной службы после публичной активации остаётся not_run.
