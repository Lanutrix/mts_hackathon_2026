# Откат

`bash deploy/rollback.sh PREVIOUS_COMMIT_SHA` от deploy проверяет SHA/realpath/RELEASE, атомарно меняет current и перезапускает только сервис проекта. После этого проверяются ready, dashboard, file→UI, auth и SSE. Предыдущий каталог не удаляется. Обратимых изменений схемы не требуется: текущая миграция только добавляет таблицы/индексы.

Восстановление БД — отдельная операция по backup-restore.md, только после сравнения сохранённых данных и остановки writer. Не заменять новые рабочие данные старым dump автоматически. Скрипт отката подготовлен, но **не исполнен на VDS**: runtime/bootstrap пока отсутствует. Реальный deployment rollback acceptance остаётся blocked, а не done.
