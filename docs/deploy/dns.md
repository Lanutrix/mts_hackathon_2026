# mts-watermelon.ru

21.11.2026 в ходе повторной проверки A-запись домена подтвердилась. Каждый авторитетный сервер ns1.timeweb.ru, ns2.timeweb.ru, ns3.timeweb.org и ns4.timeweb.org ответил 89.19.215.254. Ответы 1.1.1.1 и 8.8.8.8 совпали. На авторитетных серверах для apex запросы AAAA и CAA дали ENODATA. Ранее наблюдавшийся NXDOMAIN устарел. Правок DNS не потребовалось.

После системной установки проверить открытые 80/443, готовность приложения и конфигурацию Caddy. Выпустить TLS, проверить цепочку сертификата, SAN, перенаправление HTTP и пользовательский сценарий извне. Текущие результаты записаны в [протоколе VDS](../qa/evidence/vds-staging.json).

Конфигурация deploy/Caddyfile проверена на VDS командой caddy validate в Caddy 2.11.9. Выпуск сертификата и публичное подключение ожидают запуска системного сервиса.
