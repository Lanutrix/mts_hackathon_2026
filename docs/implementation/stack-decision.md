# ADR-W09 — стек и границы

Решение проекта: один Node 24 процесс Fastify + файловый worker + отдельный worker_thread для локального ML; React 19/Vite 8. PostgreSQL на VDS, PGlite для воспроизводимых локальных проверок Windows без Docker. Kafka, Redis, vector DB и отдельные сетевые микросервисы не нужны для измеренного объёма. SSE публикует только committed revision; полный resync закрывает потерянный cursor. Каждая из четырёх групп имеет окно 30 карточек: ограничение DOM, не усечение данных.

SQL-проекция хранит incidents с полным raw; immutable events/before/after; snapshots (hash, revision, row_count), ingest_runs, notification/read state, audit, preferences, ai_cache и ai_jobs. Snapshot metadata + immutable changes позволяют восстановить историю без полного дублирования 20-МиБ массива на каждое изменение. Демо-reset удаляет проекцию только namespace demo; audit/ingest_runs сохраняются. Это осознанное исключение неизменяемой истории, доступное только demo-admin. Схема additive, без destructive migrations.

PGlite и PostgreSQL используют один SQL-адаптер. Прохождение локального PGlite не доказывает VDS PostgreSQL: такой smoke остаётся blocked до первоначальной установки. In-memory cookie sessions после рестарта требуют повторного входа, но read state/настройки/история сохраняются в БД. Ограничение: один backend writer; горизонтальное масштабирование не заявлено.

Context7 resolve + query выполнены для Fastify, React, Motion, PGlite и Playwright. Источники: [Fastify lifecycle](https://fastify.dev/docs/latest/Reference/Hooks/), [React effects](https://react.dev/reference/react/useEffect), [Motion reduced motion](https://motion.dev/docs/react-accessibility), [PGlite Node FS](https://github.com/electric-sql/pglite/blob/main/docs/docs/filesystems.md), [Playwright projects](https://playwright.dev/docs/test-projects). Точная patch-версия не всегда индексируется Context7; совместимость проверена установленным TypeScript, сборкой и тестами, номер документации не выдан за версию сервиса.

ИИ: Xenova/multilingual-e5-small, revision 761b726dd34fb83930e26aab4e9ac3899aa1fa78, quantized q8, Transformers.js 4.3.2 / ONNX CPU. Embeddings 384 ранжируют предложения описания; сводка содержит факты полей и выбранные моделью предложения с evidence. Это extractive ML, не генеративная LLM и не доказанная причинная диагностика. Каталог ownership отсутствует — suggestedTeams пуст. Данные инициатора модели не передаются. [Модель](https://huggingface.co/Xenova/multilingual-e5-small), [исходная модель](https://huggingface.co/intfloat/multilingual-e5-small).

Motion используется только для неброского состояния карточек; initial=false не создаёт исторический шторм. GSAP не добавлен в runtime. UI хранится компактно в одном приложении; отдельный npm workspace packages/ui пока не нужен, tokens экспортированы отдельно для передачи дизайна.
