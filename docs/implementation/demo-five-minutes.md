# Защита — пять минут

## Публичный показ за 42 секунды

Откройте [учебный эфир](https://mts-watermelon.ru/simulation) на проекторе и телефоне. Первый зритель запускает общий цикл. Следующий подключается к тому же инциденту на текущем шаге. Учебный источник находится во временном файле сервера. Между источником и экраном работают тот же разбор JSON и правила классификации, что и в основном эфире.

| От начала цикла | Что меняет источник | Что видит координатор |
|---|---|---|
| 0 с | Регистрирует сбой платежей | Видны продукт, команда и срок |
| 5 с | Повышает приоритет до критического | Появляется закреплённое уведомление с названием и ID |
| 14 с | Назначает группу координаторов | Приходит новый сигнал по тому же ID, в строке видны обе причины отбора |
| 24 с | Обновляет срок | В строке и открытых текущих сведениях меняется время |
| 33 с | Передаёт состояние «Завершён» и описание результата | Появляется уведомление о завершении |
| 42 с | Начинает следующий цикл с новым ID | Журнал сохраняет последние 24 сигнала |

Откройте первый сигнал в журнале после завершения. Снимок сохраняет команду, статус и срок на момент события. Пока инцидент в эфире, ссылка в снимке открывает его текущие данные. Рекомендация под описанием предлагает проверку по состоянию источника. Решение остаётся за человеком. Зритель может открыть или скрыть сигнал, весь учебный эфир доступен по GET. Через 12 секунд после ухода последнего зрителя сервер освобождает учебный файл.

## Полный показ на защите

Перед выступлением: локальный запуск/проверенный HTTPS, оператор с demo-admin, две вкладки, отдельный терминал. Закрытый оригинал показывать только в авторизованном приватном источнике, без записи персональных данных. Синтетика не статистика МТС.

1. 0:00–0:40. Показать original-check: 44 записи, группы 0/2/1/5. Пояснить 7=Завершён, 10=Закрыт, solution не закрывает активный инцидент. Переключить на DEMO.
2. 0:40–1:20. `npx tsx scripts/mutate.ts .runtime/demo/incidents.json critical`, затем `coordinator`. Две вкладки без reload показывают одну identity в двух группах и долговечное уведомление.
3. 1:20–2:00. `deadline 2026-11-21T09:00:00Z` (или актуальный демонстрационный срок), затем `deadline null`. Приоритет не меняет срок, null остаётся «Срок не задан».
4. 2:00–2:40. `state 7`: карточка уходит, решение видно в ленте и недавних. `state 2`, затем `state 20`: Research не попадает в active critical/high, но остаётся у координаторов.
5. 2:40–3:30. Открыть карточку, получить ИИ-сводку. Назвать локальную ML-модель, показать evidence каждого тезиса, version и ограничения. Не выдавать fallback за живой анализ.
6. 3:30–4:10. ITSM-кнопка ведёт к тому же ID; экран явно помечен макетом SimpleOne. Нет настоящего write в ITSM и автоматического назначения.
7. 4:10–5:00. Показать source freshness, безопасную ошибку JSON/последнюю версию, raw export и read state, затем общий экран. Назвать измеренные p95 и среду, статус DNS/VDS и отдельно отложенные F37–F40.

Демо-панель даёт play/pause/step/reset и девять файловых шагов. После Closed следующий цикл использует новый ID; reopen Closed запрещён. Перед повтором защиты reset выполняет demo-admin только в DEMO namespace.
