# МТС Watermelon — система дизайна

Решение проекта: светлый спокойный диспетчерский интерфейс. Фон #F4F6F8, поверхности #FFFFFF, текст #17212F, вторичный #526071, декоративные границы #D5DBE3, границы элементов ввода #7B8796; critical #B42318, warning #854D0E, resolved #166534, акцент #284B8F. Состояния дублируются словами, не только цветом. Шрифт Golos Text с кириллицей, system fallback; body 16/24, metadata 14/20, heading 24/32; wallboard 22/30, 20/28 и 28/36. Табличные цифры; baseline 4px; spacing 4/8/12/16/24/32, radius 8/12. Обычная граница 1px, focus 2px #284B8F, elevation flat=0. Короткое появление 180ms только при событии, reduced motion 0ms.

Компоненты: Button, Input, Checkbox, Badge, IncidentCard, GroupColumn, SourceStatus, EventRow, Drawer, EmptyState. В Figma — 31 переменная, 6 текстовых стилей, variants и instances; в React — соответствующие CSS variables. Библиотеки Material3/Simple Design System проверены: готового dashboard с предметными полями и state/quality contract нет. Решение проекта — собственные компоненты; mapping и ограничения Code Connect описаны в [figma-code-map.md](figma-code-map.md).

Страницы Figma: Foundations, Components, User flows, Desktop, Wallboard, Responsive, States, Handoff. Экраны S01–S12, состояния loading/empty/error/offline/stale и 14 переходов прототипа. Выполнены проверки 390/1024/1440/1920/2560, keyboard, 200% zoom, reduced motion и axe в Chromium/Firefox/WebKit. 3840 отдельно не проверялся; сертификация WCAG не заявляется. Фактические результаты: [validation.md](validation.md), [test-report.md](../qa/test-report.md), [структурный аудит Figma](../qa/evidence/figma-audit.json).
