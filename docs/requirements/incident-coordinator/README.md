## Принципы границ ответственности

Координатор отвечает за **своевременную и корректную маршрутизацию, наблюдение и коммуникацию**; команда — за фактические технические действия. Предлагаемый продукт не должен по умолчанию менять продуктивную инфраструктуру, признавать инцидент решённым без допустимого подтверждения или выдавать своё решение за решение заказчика.
