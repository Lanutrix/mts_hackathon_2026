## Правила структуры и статусов

1. **Исходник не равен требованию.** Расшифровки не переписываются под позднейшие гипотезы; спорные термины помечаются.
2. **Статус обязателен:** зафиксировано в обсуждении / предположение команды / требует проверки / подтверждено внешним источником.
3. **Результаты исследования** складываются только в research/incident-coordinator/results/, с гиперссылками на первичные источники, датой обращения и перечнем ограничений.
4. **Контракты и решения** сначала обосновываются, после чего переносятся в requirements/incident-coordinator/. Не выдавать сценарий демо за факт о внутренней инфраструктуре МТС.
5. Имена файлов английскими строчными буквами; основное содержание документов — на русском; ссылки относительные, когда адресат в репозитории.
