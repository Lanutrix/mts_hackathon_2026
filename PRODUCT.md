# МТС Watermelon

<!-- impeccable:product-schema 1 -->

## Platform
web

## Stack
Delegated: пользователь явно поручил рутинные решения агенту. React, Node 24, PostgreSQL; локально PGlite. Деплой на выделенный VDS, без Vercel.

## Users
Координатор массовых инцидентов, наблюдатель и администратор демонстрации. Работа за компьютером и на общем большом экране.

## Product Purpose
Наблюдать четыре независимые группы из исходного JSON-массива и получать изменения без перезагрузки. Сохранить исходные факты и историю, показать срок, назначение и качество данных, дать полезную ИИ-сводку с основаниями.

## Constraints
Официальный кейс и уточнения имеют приоритет над историческими обсуждениями. Все пользовательские тексты русские. WCAG 2.2 AA. Публично только синтетические данные, приватные оригиналы вне репозитория. Read не означает ACK. Демо не является продуктивной системой МТС. Полный контракт: docs/requirements/incident-coordinator/.

## Decision provenance
Продуктовые факты взяты из подробного пользовательского контракта; повторное интервью пропущено по его явному указанию работать автономно и не переспрашивать рутинные решения. Установочный hook Impeccable намеренно выключен; выполняются явные audit/critique. Регистрация отдельного аккаунта не нужна.
